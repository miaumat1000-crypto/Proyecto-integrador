Convenciones de este informe

Crítico rompe la ejecución o la interfaz. Alto incumple un requisito de la guía o deja pasar datos incorrectos. Medio afecta el contrato o la mantenibilidad. Bajo es una mejora de robustez o de estilo.

En el código, cada cambio lleva el comentario # REVISIÓN (X-n), con el mismo identificador de este informe, para que puedan buscarlo con Ctrl+F. Las partes que se conservaron del trabajo de los estudiantes están señaladas con # Trabajo del estudiante. El trabajo se corrigió y se amplió; no se reescribió desde cero.

def _obtener_bytes(archivo):
    if isinstance(archivo, (str, Path)):
        return Path(archivo).read_bytes()
    if isinstance(archivo, (bytes, bytearray)):
        return bytes(archivo)
    if hasattr(archivo, "getvalue"):    # Streamlit / BytesIO
        return archivo.getvalue()
    if hasattr(archivo, "read"):        # archivo abierto
        return archivo.read()
    raise ErrorFormatoFuente(...)
Para aprender: es el patrón adaptador: una función auxiliar convierte cualquier entrada a bytes, y los tres lectores trabajan siempre sobre el mismo tipo. hasattr permite aceptar «cualquier cosa que tenga .read()» sin conocer su clase (duck typing). openpyxl.load_workbook acepta io.BytesIO, así que el lector de Excel del estudiante funciona igual.
